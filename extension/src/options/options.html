n8Tracks extension

Connection

Connect to n8Tracks

The address you open n8Tracks at, such as https://n8tracks.example.com.

This address starts with http://, so the token is sent unencrypted. Use it only on a network you trust.

Create a credential of kind Extension in n8Tracks under Settings → Credentials, with suno.sync, suno.generate, or both, and paste its token here.
