## Simple mode's Lyrics and Styles sections (#146)

- The "+" button (`aria-label="Add"`, `aria-haspopup="menu"`) opens a menu of Lyrics, Styles, Playlist, Image, Video, Audio, and Voice. Lyrics, Styles, Audio, and Voice open submenus. The menu is labelled by the "+" button, whose only name is its `aria-label`.
- Lyrics and Styles each offer **Write new** and **Use existing**. Write new opens a dialog named **Lyrics** or **Styles**:
  - Lyrics holds the same Lexical "Lyrics editor" as Advanced mode, the Undo, Redo, New draft, Saved lyrics, and full-screen buttons, and the Cowriter (with its own Close).
  - Styles holds one text area, Suno's suggested styles ("Add style: …"), Save prompt, Clear styles, and Close.
- Closing the dialog adds the section as a **chip** above the Song description: the text in the chip's `title`, and a "Remove <text>" button. The chip does not say whether it holds lyrics or styles.
- **Closing the Styles dialog showed Suno's toast "Prompt saved."**: Suno saved the style to the user's saved style prompts. That is additive (invariant 4 concerns destructive changes), and no other captured path sets Simple's styles, so the adapter uses this one and reports it with the outcome (decision TS-005-3).
- Switching to Advanced keeps what Simple's sections hold: the Advanced Lyrics and Styles boxes show it.

## Decisions

- **TS-005-1. The clip's page is recognised by its cover image.** The adapter goes to `/song/<id>`, waits for the cover image and checks that its address holds the ID, then presses the More options beside it (never one of the other eleven). Suno's 404 stops the request naming the source; so does another clip, or no page in time.
- **TS-005-2. A trashed clip is known only from n8Tracks.** Its page renders as any other, so the Trash check stays n8Tracks' availability as of the last sync (#142). A clip trashed since the last sync is opened and its action taken as for any clip.
- **TS-005-3. Simple's styles go through the Styles dialog, and Suno's "Prompt saved." is reported.** The summary line for the styles says that Suno saved them to the user's saved style prompts. No path that does not save was captured.
- **TS-005-4. A voice is chosen by its title** in the Voice picker when exactly one voice in the list has the Version's name, and verified by the form's `/voice/<persona ID>` link. The forbidden-control matcher lets an element with no role be pressed in the Voice picker only, by its text, and refuses any whose text starts with a forbidden word ("Create Voice"). In Simple mode the voice stays by hand.
- **TS-005-5. The untitled Key popover is recognised by everything it holds.** It is allowed only while every control in it is a note, Any, Major, Minor, or Apply; any other untitled dialog, or this one with any other control, fails closed. A tab list or group inside a recognised dialog is a container, not a control the dialog must list.
- **TS-005-6. "Overwrite Styles?" is answered Overwrite**, as "Overwrite Lyrics & Styles?" is: the Version's own values are filled afterwards.
- **TS-005-7. A Mashup's second song and further Inspiration songs are added by hand.** The extension loads the first through the clip's menu, then asks the user to add the rest and press Continue, and verifies every one on the form before filling anything else.
- **TS-005-8. Duration back to Auto is by hand** when the form shows Custom: the icon that resets it has no name. Choosing Custom is automated.
