# TS-003: Suno pages and clip data for every creation mode

**Run:** 2026-10-05, in the maintainer's signed-in browser, driven through Claude in Chrome. A new workspace was created for the spike. The agent filled the Create form in each of the five modes, and the maintainer clicked Create each time (the agent never did). All five used v6-mini, the cheapest model; the whole run cost 42 credits, Max Mode included. An in-page recorder kept each Suno request's address, body, status, and timing, and the response body. It kept no headers and skipped the sign-in host. Raw captures are in the ignored `docs/.notes/suno/`. Sanitized fixtures and page snapshots are in `extension/fixtures/suno/` (see its README), and the field map is in `docs/suno-import-field-map.md` and `.json`.

## Findings

### Where each Create option is returned

`docs/suno-import-field-map.md` has the full table. In short:

- **Returned in the feed, unchanged:** lyrics, Speech script, Simple prompts, exclude styles, Max Mode, Weirdness and Style Influence (as fractions: 70 → `0.7`), Variety (index 0–4), title, workspace, the Sound description, and the Sound loop, tempo, and key (`sound_configs`). The model label is in `metadata.model_badges.songrow.display_name` (`V6-MINI`), for Songs only.
- **Returned in the feed, but rewritten:** **styles** and the Speech **tone**. `metadata.tags` in the feed is a long description Suno writes ("acoustic folk, banjo" came back as 205 characters). The Create response still has the submitted text. Sounds are the exception: their description is kept as typed.
- **Never returned (request only):** vocal gender (`metadata.vocal_gender: "f"`), duration (`duration: 30`, sent only when Custom), Personalize (`use_personalization`), Speech background music (`metadata.backing_music`), and the Sounds model label. The feed's `metadata.duration`, `avg_bpm`, and `key` are Suno's measurements of the audio, not the settings.
- **Mode and kind:** `metadata.is_speech` marks Speech and `metadata.task: "sound"` marks Sounds. Simple clips carry `gpt_description_prompt` and `task: "agentic_thinking"`. The request's `create_mode` (`simple`/`custom`) is never returned.
- **Simple mode sends the Advanced form's Variety.** Songs Simple sent `aug_creativity: 4`, the value then set on the Advanced form. Speech Simple sent no sliders.
- **Suno fills in a blank title.** A blank title is replaced by one Suno writes, so on import a submitted title cannot be told from Suno's.
- **Model names do not identify the label.** Every v6-mini song reported `major_model_version: "v6"`, `model_name: "chirp-goose"`, and the request said `mv: "chirp-goose"`. Sounds reported `chirp-seeds`, then `chirp-sfx`, with an empty `major_model_version`.

### How lists are paged, and what makes the page ask for more

| List | Request | Paging | What the user does |
|---|---|---|---|
| Library (all songs) | `POST /api/feed/v3` with a `user` filter | Cursor: send the last `next_cursor` as `cursor`; stop when `has_more` is false. 20 per page. | Scroll the Library › Songs list to its end. |
| A workspace's songs | `POST /api/feed/v3` with a `workspace` filter | First page as above (`cursor: null`, `limit: 20`). The next page was not exercised (the spike workspace had one page). | On /create the library pane has page buttons (`Previous page`, `Next page`, a page-number box). Toggling a filter re-requests the first page. |
| Trash | `GET /api/clips/trashed_v2?limit=20[&cursor=…]` | Cursor in the query; `num_total_results` was 0 even with 20 results, so it cannot be trusted. | Open Library › Trash (`/me/trash`) and scroll. |
| Workspaces | `GET /api/project/me?page=N&sort=max_created_at_last_&show_trashed=false&exclude_shared=false` | Page numbers, 20 per page, with `num_total_results` (96 here). | Scroll Library › Workspaces (`/me/workspaces`) or the Workspaces list on /create. |
| Playlists | `GET /api/playlist/me?page=1&show_trashed=false&show_sharelist=false` | Page numbers with `num_total_results` (10 here; one page). | Open Library › Playlists, or the Create form's "+ Inspo" picker. |
| A playlist's songs | `POST /api/unified/feed` `{ feed_id: "generic_playlist:<id>", cursor, page_size: 50 }` | A `cursor` is sent, but no next-cursor field appeared for 8 songs; paging past 50 is not determined. | Open the playlist page. |
| Voices | `GET /api/persona/get-personas/?page=1` | Page numbers with `total_results`. | Open "+ Voice". |

### Answers to the open questions

- **Artwork can be read without credentials.** A request to `cdn2.suno.ai/image_<id>.jpeg` (and `image_large_…`) with no cookies or credentials returned the image, with `Access-Control-Allow-Origin: *`.
- **Voice can be selected reliably, by name.** The picker lists the maintainer's voices by name and image; the image address holds the persona's `root_clip_id`, but no persona ID appears in the page. Names were unique (2 voices). `GET /api/persona/get-personas/` maps each name to its `id`, the value a clip later carries as `metadata.persona_id`. The adapter selects by name when the name is unique among the user's voices and verifies by the image's clip ID. When names collide, Voice is a manual step.
- **TS-002's open questions** (`clip_roots` on Cover clips; the feed for a clip whose source is trashed) were not reached in this session and remain open.

### Other observations

- **Choosing Remix › Cover can ask first.** When the Create form already has lyrics and styles, Suno shows "Overwrite Lyrics & Styles?" with Overwrite and Keep Current (`page.overwrite-lyrics-styles-dialog.html`). The adapter must answer it (Overwrite) and then verify.
- **Filling lyrics saves a draft in Suno.** Loading lyrics into the form (here, by Cover) made the page call `POST /api/lyrics-projects` and `…/flush`, adding an entry to the user's Saved lyrics. This creates content but deletes nothing.
- **Form state is shared and remembered.** Both title inputs and the Advanced Variety are shared across modes, and the form is restored when /create is reopened.
- **Sliders take arrow keys, not Home or End.** Duration moves in 5-second steps from 10 to 360. Weirdness and Style Influence move in steps of 1. Variety moves in steps of 1 from 0 to 4.
- **Max Mode is accepted on v6-mini**; the Create screen did not refuse it.
- **The finished clip's playback audio** is in `media_urls[0]` (`m4a-opus`, progressive, on a CloudFront host) and loads without credentials. `audio_url` is a placeholder (`…/api/forbidden`). See TS-004.
- **The Create request carries an anti-bot `token`** (with `token_provider`) and a `create_session_token`. The extension must never copy or log them (invariant 6).

## Decision

1. **Fields that cannot be captured on import:** styles and Speech tone (the feed rewrites them), vocal gender, Speech vocal gender, duration mode and seconds, Personalize, Speech background music, the Sounds model label, and Simple-mode image and video. Import marks them `not returned`. An observed Create records them from the Create request body, read by the page-side wrapper in the tab where Create was clicked. The wrapper keeps only the mapped fields; the token is never copied.
2. **Entries in `docs/suno-adapter-field-map.md` that must become `manual`:** none. Every control was set and read back in this session. The adapter must handle the Overwrite dialog and set sliders with arrow keys. Simple-mode image and video were already `manual`.
3. **Voice can be selected reliably** when the persona's name is unique among the user's voices, verified by the image's `root_clip_id`. Otherwise it is manual. `songs.*.voice` stays `source`.

## Deviations from the plan

- The import map has a third path, `createRequest`, beside `feed` and `create`, because six fields exist only in the request.
- The checker is `extension/scripts/lib/check-fixtures.ts` with a vitest test, not `extension/scripts/check-fixtures.mjs`. Every other extension script is TypeScript run by Node, and ESLint and `tsc` cover only `.ts` here. A `.mjs` file would have been outside the warnings-are-errors gate (invariant 8).
- The paging fixture is two consecutive Library pages plus the last page of a workspace's list, not three pages of one list. The Library had more pages than the session reached.
- Not exercised (marked `unverified` in the map): Simple-mode Add Lyrics, Add Styles, Image, and Video; male vocal gender; Variety Off, Normal, and Extra; Sound One-Shot, Auto BPM, Any key, and major scale; models other than v6-mini.

## Not determined

- How v6 and v6-wild appear in the request (`mv`) and badges.
- What the feed returns for a clip whose source was trashed, and `clip_roots` on Cover clips (left from TS-002).
